A short field guide

Why circuits fail — and why some faults disappear

A digital circuit is a network of Boolean operations. A fault at one gate changes the signal there, but it only becomes a system error if the changed value travels to an output and changes the answer.

01 / PROPAGATION

Faults need a path to the output

A gate error can be blocked by a later logic condition. For example, an AND gate outputs 0 if either input is 0, so a faulty 1 on the other input may be hidden. This is fault masking.

system error = output(faulty) ≠ output(correct)
02 / BERNOULLI MODEL

One coin flip per gate

In the Bernoulli model each gate independently fails with probability p. For a simple series chain of n essential gates, every gate must work.

R = (1 − p)n   ·   P(failure) = 1 − R
03 / TIME TO FAILURE

Constant rate or aging?

Exponential reliability assumes a constant failure rate λ. Weibull adds a shape β: β > 1 models increasing wear-out risk; β < 1 models early-life failures.

Rexp(t) = e−λt   ·   Rweib(t) = e−(t/η)β
04 / MONTE CARLO

Estimate by repeating the experiment

The simulator samples many fault patterns and input combinations. Reliability is the fraction of trials whose observed output remains correct. More trials reduce sampling noise.

R̂ = successful trials / N   ·   SE ≈ √[R̂(1−R̂)/N]
05 / ARCHITECTURE

Ripple carry vs. lookahead

A ripple-carry adder passes carry from one bit stage to the next: it is compact and easy to build, but the carry path grows with bit width. A carry-lookahead adder computes propagate and generate terms so carries can be resolved in parallel, trading more logic and wiring for lower delay. Different structures also create different fault paths and masking behavior.

Pi = Ai ⊕ Bi   ·   Gi = AiBi   ·   Ci+1 = Gi + PiCi
06 / FAULT TYPES

Stuck-at and transient faults

A stuck-at-0 or stuck-at-1 fault holds a gate output at a fixed logic value. A transient bit flip changes a value for one evaluation. The selected fault model controls how likely failures are; the selected fault type controls what is injected in the trace.

SA0: y = 0   ·   SA1: y = 1   ·   transient: y → ¬y
Reading the charts: sensitivity is the share of sampled input patterns for which a fault at a gate changes an output. High sensitivity means that gate is more exposed in this experiment; it does not, by itself, mean that the gate is more likely to fail.
